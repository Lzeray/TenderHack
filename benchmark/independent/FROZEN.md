# Заморозка test-части независимых наборов (v2)

Дата заморозки: 2026-10-10. До заморозки ни одна система на этих наборах не запускалась.

## Что заморожено

Строки со `split = "test"` в трёх наборах:

| Набор | test-кейсов | sha256 test-части |
|---|---|---|
| `suites/natural.jsonl` | 313 | `6ec6562ed4e7794f3cacba8034eaa0ab17f37a44331a213cd1711bfe94d2790a` |
| `suites/contradictions.jsonl` | 102 | `fb0fc090e1c3e0ca80f12cf99306b4d3052de02fd29b5aee2f2a6061a1996588` |
| `suites/out_of_scope.jsonl` | 32 | `12b70da55dfe476f3e6102e1afafff49328211cf99abb805db5a8e36916e0a51` |

Те же хеши лежат в машиночитаемом `test_manifest.sha256`. Хеш считается по точным строкам файла со
`split=test`: в порядке файла, через `\n`, в кодировке UTF-8 (функция `generate.test_hash`).

## Условия генерации

| Параметр | Значение |
|---|---|
| Генератор | `benchmark/independent/generate.py` |
| `SEED` | 20261010 |
| Соль сплита | `iv2-a` |
| Доля test | 30% по хешу наименования |
| База | `data/ktru.sqlite`, снимок `nsiKTRUNew_all_actual_20261003020003`, `as_of = 2026-10-09`, `importer_version = 1.0` |
| Окружение | Python 3.12.3, pymorphy3 2.0.6, словари pymorphy3-dicts-ru 2.4.417150.4580142 |

Если повторная генерация на той же базе с теми же версиями даст другие test-хеши, это ошибка: генерация
детерминирована и от `PYTHONHASHSEED` не зависит (проверено).

## Как проверить

- `python -m benchmark.independent.run ...` — сверяет хеши при каждом прогоне. Результат пишется в
  `meta.frozen` отчёта и в шапку Markdown.
- `python -m pytest -q tests/test_independent_metrics.py` — тест
  `test_suites_gold_matches_catalog_and_manifest` пересчитывает эталон по базе и сверяет хеши.
- `python -m benchmark.independent.generate` — пересобирает наборы и предупреждает, если test-часть
  разошлась с манифестом. Манифест он при этом не переписывает. Переписать манифест можно только явно
  флагом `--write-manifest`.

## Правила

1. По test смотрим только агрегаты: таблицы `run.py` и блок `by_split.test`. Тексты и разборы отдельных
   test-кейсов не открываем. Для прогонов по test есть `--hide-test-cases`.
2. Систему настраиваем только на dev: алиасы, правила, пороги, словари, промпты.
3. Если test-часть изменилась, это новая версия наборов. Создаём новый раздел ниже с датой, причиной
   и новыми хешами. Результаты разных версий не сравниваем.
