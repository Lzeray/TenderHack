# Слияние matvey_develop + main + Lenaz (11.10.2026)

Ветка `merge/all-2026-10-11` от `matvey_develop` (`769a8d7`). `Lenaz` = `main` (`28189b2`) + один коммит
(`c18c55b`, Qwen3.5 для дополнительных характеристик), поэтому влита одна ветка `Lenaz`.

## Что пришло из main и Lenaz

- `c7ed8a2` — отрицание не перескакивает через повтор слова («мех не натуральный натуральная кожа»).
- `f10031c` — бенчмарк сокращён до 313 test-кейсов `natural`; удалены остальные наборы v1/v2/метаморфные и их тесты
  (поэтому pytest 289 → 255).
- `455a7b6`, `28189b2` — новый фронтенд из aydar: колонки, «Уточнение», «Выбранные характеристики», «Обязательные
  характеристики»; скрытая строка «тип; ключ: значение» в нём сохранена.
- `c18c55b` — `ktru_assist/llm/extra_characteristics.py`: после Enter Qwen предлагает дополнительные характеристики
  для нераспознанных фрагментов (на код не влияет, ответ модели проверяется по цитатам).

Конфликты: `config.py` (обе ветки подняли extractor до 2.7 — теперь 2.8 с обоими изменениями) и
`tests/test_catalog_real.py` (оба теста). Фронтенд и сборка совпадали с `main`.

  отрицание; регистр и «ё»; английская раскладка; опечатка + Enter; противоречие и его исправление; дописывание
