# Дополнительные признаки через Qwen3.5

Отдельный проход `/api/search` включён по умолчанию (`EXTRAS_LLM=on`).
Существующий интерфейс отправляет `stage=submitted` по Enter или после 1000 мс
без ввода. Черновой поиск через 200 мс не вызывает эту модель.

После основного разбора Qwen получает исходное описание, нераспознанные
фрагменты, известные свойства КТРУ/СТЕ и уже заполненные дополнительные свойства.
Возвращает только пары «характеристика — конкретное значение» с дословными
цитатами. Сервер проверяет цитаты, связь с неразобранным фрагментом, наличие
значения в цитате (допускается нормализация словоформ), исключает известные
свойства и оценочные формулировки. Названия новых характеристик не перечисляются
вручную. Ответ добавляется в существующий блок дополнительных характеристик.
Код КТРУ, тип товара, ограничения и каталог не изменяются.

Примеры желаемого поведения (инференс в этой доработке не запускался):

- «Молоток с резиновой ручкой» → «Материал ручки: Резина», если основной
  разбор не определил этот признак и его нет в свойствах КТРУ/СТЕ этого товара.
- «Крепкий и дешевый молоток» → никаких дополнительных характеристик.
- Отсутствующие в описании значения не угадываются и не дополняются.

## Подключение

Используется уже установленная модель на локальном сервере Ollama. Приложение
не скачивает веса и не вызывает `/api/pull`. Ollama должен быть доступен до
использования дополнительного разбора.

Официальный идентификатор подходящей небольшой модели — `Qwen/Qwen3.5-4B`;
Hugging Face отображает её общий размер округлённо как 5B. Отдельного
официального тега `qwen3.5:5b` в Ollama нет. Поэтому по умолчанию используется
существующий тег `qwen3.5:4b`, а не несуществующее имя.

Источники: [модель Qwen](https://huggingface.co/Qwen/Qwen3.5-4B),
[теги Ollama](https://ollama.com/library/qwen3.5),
[API chat](https://docs.ollama.com/api/chat).

Переменные окружения:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `EXTRAS_LLM` | `on` | `off` отключает дополнительный разбор |
| `EXTRAS_LLM_MODEL` | `qwen3.5:4b` | Имя уже установленной модели в Ollama |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | Адрес локального Ollama |
| `EXTRAS_LLM_TIMEOUT` | `20` | Таймаут одного запроса в секундах |

В Docker Compose адрес по умолчанию — `http://host.docker.internal:11434`;
для Linux добавлен `host-gateway`. Можно задать адрес своего доступного сервера
через `OLLAMA_URL`. Конфигурация основного LLM (`LLM_MODEL`, `LLM_MODE`) независима.
Для Qwen отключено thinking, температура 0, ответ ограничен JSON Schema.

При недоступности модели основной результат сохраняется; ошибка доступна
в `providers` с именем `qwen_extras`. Устаревший результат при новом вводе
отбрасывается по ревизии. Модельные значения пересчитываются из актуального
текста, не сохраняются как ручные решения и не переживают удаление фрагмента.

Тесты и инференс не запускались, веса не скачивались по требованию заказчика.
