# Подстановка единиц измерения и разбор габаритов по типичным соотношениям

Черновик перед реализацией (10.10.2026). Пробы текущего поведения — `reports/exp/units_probe.txt` (не в git).

## Что сейчас

| Запрос | Сейчас |
| --- | --- |
| молоток слесарный длина от 120 | «не указана единица» — не проверяется |
| пассатижи слесарные длина 180 / 18 | то же + вопрос «укажите значение длины» |
| шкаф для одежды высота 180 / 1,8 | то же |
| шуруповерт крутящий момент 40 | то же, хотя в КТРУ у свойства единственная единица — Н·м |
| дрель мощность 600 / 0,6 | то же |
| куртка рост 170 | уровень 3 подсказывает «170 см» (по КТРУ), но признак не проверяется |
| стол обеденный 120х80х75 | работает: раскладки перебираются в мм, см, м |

Почему одного КТРУ мало: ступени часто открыты по краям («< 1200 мм», «≥ 1000 Вт»), поэтому «600 кВт» и «120 м»
формально допустимы. Различать единицы помогает статистика выгрузок (уровень 2) и соотношения внутри запроса.

## Идея

Число без единицы у числового свойства — это несколько гипотез «число + единица той же размерности, что у
свойства в КТРУ». Для каждой гипотезы собираются свидетельства, побеждает единственная правдоподобная; если
правдоподобны несколько — вопрос «в каких единицах?» с вариантами и числами. Единицы другой размерности
(В вместо Вт) не рассматриваются никогда.

## Свидетельства (по убыванию силы)

1. **Единственная единица размерности.** У свойства в КТРУ значения в Н·м, и других единиц крутящего момента
   в справочнике нет → Н·м без вопросов. Так же единица в названии свойства («Крутящий момент (Нм)»).
2. **Единица соседних признаков.** В том же описании у другой длины указаны сантиметры («высота 180 см,
   ширина 80») → для длины без единицы сначала проверяется см. Используется как сильная подсказка, но не
   вопреки КТРУ и выгрузкам.
3. **Допустимость по КТРУ (уровень 1).** Гипотеза, при которой значение не подходит ни одной позиции области,
   отбрасывается. Открытые ступени («≥ 1000 Вт») здесь не различают — поэтому этого мало.
4. **Типичность по выгрузкам (уровень 2).** Доля моделей типа со значением в пределах ±10 % (как в D4).
   «Молоток, длина 120»: 120 мм — обычная длина, 120 см и 120 м — ни одной модели.
5. **Запись числа.** «1,8» у длины мебели — скорее метры, «1800» — миллиметры; «0,6» у мощности — кВт, «600» — Вт;
   «0,5» у массы — кг, «500» — г. Только как слабая подсказка при прочих равных.
6. **Запасной вариант без выгрузок.** Если у свойства мало моделей в выгрузках — распределение той же оси по
   всему направлению («длины» мебели, «массы» инструмента) и единица, в которой КТРУ хранит значения.

**Решение:** единица подставляется, если её правдоподобие хотя бы в N раз выше следующей (стартовое N = 10,
калибруется на оценке) и она не противоречит КТРУ. Иначе — вопрос с вариантами. В интерфейсе подставленная
единица видна («мм — подставлено») и меняется одним действием; в истории преобразований — шаг «единица
подставлена: …, основание: …».

## Габариты: соотношения между осями

Сейчас раскладка оценивается по каждой оси отдельно. Добавить совместные зависимости, посчитанные по выгрузкам
для моделей, у которых указаны все оси:

- **Порядок осей по величине** для типа: у шкафа обычно высота > ширина > глубина, у стола — длина > ширина,
  высота 70–80 см, у стеллажа высота наибольшая. Доля моделей с каждым порядком — множитель правдоподобия.
- **Типичные отношения** (высота/ширина, ширина/глубина): «шкаф 80×50×180» с отношением высота/ширина 2,25 —
  обычный; «180 в ширину, 80 в высоту» — редкий.
- **Одна единица на все числа** габаритов (если не указано иное); «1,2 м × 60 см» — разные единицы, явно указанные.
- **Явные связи между названными свойствами** (проверка, уровень 3): высота сиденья < общей высоты, глубина
  сиденья < общей глубины, масса нетто < брутто — пары, где «A ≤ B» выполняется у ≥ 99 % моделей выгрузок.
  Нарушение — предупреждение «возможно, перепутаны значения», без исправления.

## Дополнительные условия

- Не подставлять единицу у **счётных** свойств («3 полки» — штуки, уже так) и у **дискретных** значений
  («размер 48»).
- Не подставлять, если у числа **есть слово, похожее на единицу** с опечаткой («120 см.» распознаётся; «120 смм» —
  отдельный случай опечатки в единице: не исправляется автоматически, как и сейчас).
- Диапазон «от 120 до 140» — одна единица для обеих границ; «от 1,2 до 140» — подозрительно (разная запись),
  вопрос.
- Подставленная единица **не меняет числа пользователя**: «1,8» остаётся «1,8 м», а не «1800 мм».
- Уровень 3: подсказка «нет единицы» больше не нужна там, где единица подставлена; остаётся вопрос, если единица
  неоднозначна.
- Оценка: из чисел бенчмарка и реальных значений выгрузок (отложенные производители) убрать единицу и
  измерить: доля подставленных, точность подстановки (цель — не ниже 99 %), доля вопросов.

## Решения команды (10.10.2026)

1. **Подставленная единица может вести к автоматическому коду** без подтверждения; в характеристиках видна
   пометка «подставлено» и единицу можно сменить одним действием.
2. **Число без единицы и без названия свойства** («молоток 500», «стол 120»): смотреть распределения значений
   по свойствам типа; подставлять пару «свойство + единица», если уверенность высокая, иначе — вопрос.
3. **Связи между названными характеристиками** (высота сиденья < общей высоты, нетто < брутто) — сейчас,
   предупреждением без исправления и без влияния на код.

## Журнал

### U1. Единица у названного свойства (10.10.2026)

Модуль `ktru_assist/unit_infer.py`, вызывается в движке после разбора габаритов, до проверки по КТРУ.
Признак получает `unit_inferred = true` и пояснение «единица подставлена: мм (основание)»; в таблице
характеристик под единицей — «подставлено».

Оценка гипотезы «число + единица»:
- точка — доля моделей выгрузок со значением в пределах ±10 %; «от / до / диапазон» — доля моделей,
  удовлетворяющих условию (для «от 120» мерить точку неверно: «≥ 120 мм» выполняется почти у всех молотков);
- у одностороннего условия граница должна лежать рядом с реальными значениями (от p01/3 до p99·3):
  иначе «до 40 м» для рукоятки молотка было бы так же правдоподобно, как «до 40 см»;
- статистика ищется по названию свойства, затем по общей оси, затем по слову-оси того же типа
  («Длина рукоятки» → «Длина»);
- без выгрузок — единица значений КТРУ ×3; соседний признак той же размерности с единицей ×10;
  запись числа (дробное < 10 — крупная единица, ≥ 1000 — мелкая) ×2;
- гипотеза, недопустимая по КТРУ ни для одной позиции, отбрасывается; одна оставшаяся — подставляется;
- подстановка при перевесе ≥ 10×, иначе вопрос «В каких единицах …?» с вариантами.

Пробы на реальном каталоге (все без вопроса о единице):

| Запрос | Подставлено |
| --- | --- |
| молоток слесарный длина от 120 | мм (подходят ступени ≥ 150 мм …) |
| молоток слесарный длина рукоятки до 40 | см |
| молоток слесарный масса 500 | г |
| пассатижи слесарные длина 180 / 18 | мм / см |
| пассатижи слесарные длина от 160 до 200 | мм |
| шкаф для одежды высота 180 / 1,8 | см / м |
| дрель мощность 600 / 0,6 | Вт / кВт |
| шуруповерт крутящий момент 40 | Н·м (единственная единица) |
| стеллаж нагрузка на полку 50 | кг |
| куртка рост 170 | см |

На fixture-каталоге (статистики нет) «пассатижи длина 180» — вопрос: 180 мм, 180 см и 180 м допустимы по КТРУ
(открытая ступень «> 200 мм»), а перевес единицы хранения ×3 меньше порога. Бенчмарк без изменений; на 600
реальных названиях 6 изменений, все верные (рост и обхват головы → см, размер перчаток 8 → дюйм, как в КТРУ).
